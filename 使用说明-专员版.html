13 分钟启动

不需要安装任何东西。

第一步：双击文件夹里的 启动工作台.bat。
第二步：等 2~5 秒。黑色的命令行窗口会停留，浏览器会自动打开一个页面。
第三步：页面顶上会显示"专员版"和当前时间——这就是你以后每天上班要打开的工作台。
关闭：关掉那个黑色窗口，程序就退了，数据自动存好。
小提示：如果窗口里显示的地址不是 127.0.0.1:5270，说明这个端口被别的程序占了， 系统会自动换 5271、5272…你只要点窗口里显示的那个地址就行。
完全离线。整个工作台装在你电脑里，不连公司服务器、不上外网。拷贝整个文件夹到 U 盘，带回家也能用。

2界面怎么看

打开后会看到这样一个界面：

左侧深色是导航条，中间白底是你正在操作的页面

左侧导航条按"工作台 / 人事 / 招聘 / 合同 / 考勤 / 薪酬 / 知识工具"分组，点击就能切换模块。 顶部小字右上角的"专员版"是当前角色；旁边是当前日期时间。 中间主体你正在做的具体工作。所有数据修改完即保存，不用再点"保存"按钮。

导航条分成 7 组，包含了 12 个功能页。下面这一节告诉你"每天 10 分钟"要做的几件事；之后按你日常会碰到的场景，一个一个讲。

3每天 10 分钟做这些事

不需要把所有模块都点一遍。每天只需 3 步：

  1. 打开 待办中心（首页）—— 这里会列出今天要处理的合同到期、转正、面试、漏打卡等所有提醒。
  2. 逐条点"完成"。有疑问的先放着，别一键完成。
  3. 翻一下"今日面试"卡片：今天有谁要来面试、几点、几楼会议室。
待办中心是系统每天早上根据合同到期日、试用期、面试时间自动生成的；不是要你每天手动录入的。

4场景一：我刚来，今天该看什么

回答：进首页"待办中心"。

你刚到工位、还没打开 Excel 之前，先点导航条最上方的"待办中心"。

它会告诉你：

  • 合同 30 天内到期有几个人 —— 该去续签了
  • 今日面试有谁 —— 会议室预约、面试官时间对一对
  • 7 天内试用期到期谁 —— 该做转正评估了

每条待办右侧有一个"完成"按钮——点完就从列表里消失。忘了点也没事，明天它还在，不会丢。

如果系统没有列出的事（比如突然要做团建），你也可以点右上的 + 手动添加 自己加一条。

5场景二：合同要到期、试用期要转正

回答：进"合同台账"。

合同台账会按"紧急程度"分四块摆好：

区域看什么
🔴 7 天内到期 / 已过期最紧急，今天就要打电话给员工。
🟡 8~30 天内到期这一两周内要续签完。
🟢 31~60 天内到期提前规划，提前准备新合同。
📋 全部合同看完整名单。

第一次用：把现有台账导入进来

点右上角 Excel 批量导入 → 下载模板 → 把你们现在用的合同表复制进模板 → 上传。

模板的列是：合同名称 / 人员 / 开始日期 / 结束日期 / 第几次合同 / 合同类型 / 状态 / 试用期开始 / 试用期结束 / 备注。日期格式用 2026-08-31 这种纯数字格式最稳。

系统会自动提醒的两类情况

  • 到期前 60 / 30 / 7 天 → 弹待办，再不续签就过期了。
  • 第 2 次合同到期前 90 天 → 特别预警：按《劳动合同法》第十四条，下一次就应该签无固定期限合同（除非员工主动要求签固定期限）。这是法律要求，千万别漏。

单个新增或修改

点 + 新增合同，逐项填；点列表里的"编辑"按钮能改。改完刷新页面即可看到新状态。

6场景三：今天收了一堆简历

回答：进"简历管理"。

简历管理分三块：岗位、初筛条件、候选人

第 1 步：先把岗位建出来

点 + 新建岗位，比如"Java 高级开发工程师"。填上部门、学历要求、工作年限、城市、期望薪资上限、需要什么技能关键词。

合规提醒：系统不会让你按性别、婚育、户籍筛人。年龄项是"工作年限"——这两件事差别很大，请一定按"工作年限"填，不要输入年龄段。

第 2 步：批量导入简历

点 批量导入简历。支持：

  • 从 BOSS、51job、智联下载的 PDF 文字版（直接用）
  • docx、txt
  • 整个 ZIP 压缩包（系统会自动解压）

点"归入岗位"下拉框，把这批简历挂到你建好的岗位下面，然后点上传。系统会：

  1. 把简历内容自动读出来（不需要联网，是本机程序解析的）
  2. 识别姓名、手机、学历、学校、工作年限、当前公司、当前职位、期望薪资……
  3. 同样的文件不会重复入库；同名同手机号会自动合并到同一个人
扫描件 PDF（就是图片组成的 PDF，比如拍照扫描的）系统会打上"扫描件·待人工识别"的红色标签——这种需要你打开原文看一下，系统不能替你看图。

第 3 步：设筛选条件 → 一键分档

回到"简历管理"首页，"初筛条件"那块有 5 个软权重（年限 / 院校 / 管理 / 稳定性 / 技能）和 2 个阈值（通过、待定）。默认值是够用的，新手可以先不改。

点 应用条件并筛选。结果分三档：

分档分数建议
🟢 通过≥ 80主动联系，安排面试
🟡 待定60~79看下简历再定
🔴 不通过< 60 或硬条件不达标礼貌回复不匹配

硬条件（比如"必须本科"、"必须 3 年以上"）没达标的，直接归到"不通过"档，软评分再高也救不回来——这是为了合规。

第 4 步：修改识别错的字段

点候选人右边的"查看/修正"打开详情页。页面里黄色背景的字段是低置信度的——系统不太确定，建议你人工核对一遍，直接改后保存即可。

7场景四：安排一场面试

回答：进"面试安排"。

从简历页面点"安排面试"会自动带出候选人姓名；从导航条直接进就手动填。

必填项：

  • 候选人姓名（必填）
  • 开始时间、结束时间（点击日期框右边的小箭头弹出日期选择器）
  • 面试官（可填多个，逗号分隔，比如"张经理, 李总监"）

选填：

  • 轮次（一面 / 二面 / 终面）
  • 方式（现场 / 视频 / 电话）
  • 地点 / 会议号（视频面试填会议号）

状态默认是"待确认"。面试官确认后再点状态切换为"已预约"。面试当天 / 前一天系统会在待办中心提醒你。

面试结束后，把状态切到"已完成"或"爽约"。目前没有在线评价表，你把面试官口头反馈记在"备注"里即可。

8场景五：新员工入职怎么录档案

回答：进"员工档案"。

顶部是统计卡，下方是员工列表

方式 A：单条录入（个位数入职用）

点 + 新增员工，按提示填：工号、姓名、性别、出生日期、手机、邮箱、部门、岗位、入职日期、试用期到期、状态、学历、身份证、银行卡、备注。

敏感字段：身份证 / 银行卡——保存后页面默认显示为 110***********1234 这种掩码，防止旁边有人瞥到。点"编辑档案"后想改字段？留空就不会改原值（这是为了避免你一不小心把它清空了）。要改就重输完整新值。

方式 B：批量导入（推荐给 10 人以上入职）

点 下载导入模板 → 拿到 Excel → 把信息复制进去 → 点 Excel 批量导入 上传。

列是 15 列，注意日期一律用 2026-09-01 这种横杠格式。手机号可以是字符串（前面加 ' 或设置单元格为文本）。

员工档案详情页里还能做什么

  • 异动时间轴：下方"添加异动"可以记录入职 / 转正 / 调岗 / 调薪 / 离职。每次变动点一下，完整的时间线就留下来了，将来不用翻聊天记录。
  • 档案信息右侧的"身份证/银行卡"是掩码显示，鼠标点击也不会展开明文——这是为了保护员工隐私。

9场景六：员工来问"工资怎么少了"

回答：进"工资答疑"。

先把每月工资明细批量导入：

点 下载导入模板 → 填入数据（月份 / 姓名 / 基本工资 / 绩效 / 补贴 / 加班费 / 社保 / 公积金 / 个税 / 其他扣款 / 实发 / 备注）→ 上传。

员工来问"我这个月是不是发少了"，你：

  1. 左侧选月份、选员工
  2. 看到明细：基本工资、绩效、补贴、加班费、五险一金、个税、其他扣款一目了然
  3. 页面下方有"常见差异原因"参考表，挨个对照：是不是请假扣款、是不是社保基数调整、是不是个税累计预扣上档了……

核对后能精准回答员工哪一笔扣的是什么，不用打电话问财务。

10场景七：考勤异常表怎么批

回答：进"考勤异常"。

每月初拿到上月的考勤异常 Excel：

下载导入模板（列：姓名 / 月份 / 日期 / 异常类型 / 原因）→ 把异常粘贴进去 → 上传。

上传后：

  • 顶部"本月待确认"卡片显示还剩多少条没处理
  • 左侧"全部月份"下拉框可筛历史月份
  • 勾选多条 → 选状态（已确认 / 已处理）→ 填"处理备注"（比如"已通知员工本人"）→ 点 批量处理所选

处理完的会自动从"待确认"里掉出去，月底做汇报时不用再对一遍。

11场景八：员工问"我还有几天年假"

回答：进"假期计算"。

左侧下拉框选员工（前提是员工档案里已经有他的入职日期），系统自动按司龄算年假：

累计工龄（含之前的工龄）法定年假
满 1 年不满 10 年5 天
满 10 年不满 20 年10 天
满 20 年15 天

如果员工之前在别的公司工作过很多年，下方"社会工龄"那里手动填上即可（系统会自动取司龄和社会工龄的最大值）。

当年新入职的：年假按当年剩余日历天数折算——比如 8 月入职满 1 年的，年假只有 5 × (153÷365) ≈ 2 天（不足 1 天不计）。这是《职工带薪年休假条例》第五条规定的。

婚假 3 天、产假 98 天是法定参考值，公司制度另有规定的按公司制度来。

12场景九：被反复问同样的问题

回答：进"常用回复"。

这是用得最频繁的模块。系统已经预置了 42 条常见问答，分类包括：

  • 📅 考勤假期（10 条：年假、婚假、产假、陪产假、丧假、病假、事假、调休、漏打卡、加班）
  • 💰 薪酬福利（8 条：发薪日、工资条、绩效、加班费、年终奖、入职离职当月工资、工资异议处理）
  • 🏥 社保公积金（8 条：缴纳说明、缴存比例、社保卡、转移、提取、生育津贴、断缴影响、个税专项附加扣除）
  • 📝 入职离职（8 条：入职材料、合同签订、试用期、离职流程、离职证明、交接、档案、竞业限制）
  • ✈️ 报销差旅（5 条：报销流程、差旅标准、打车、发票、预支借款）
  • 📄 其他（3 条：员工证明、工牌与门禁、福利与活动）

最常用的两种方式

方式 1：搜关键词。比如员工问"年假怎么算"，你在搜索框输"年假"，列表立刻过滤；点"复制"按钮，把整段话复制到微信 / 钉钉发给员工。

方式 2：快捷编号。4 个有快捷编号的：/nj（年假）//hj（婚假）//gz（工资）//rz（入职材料）。

怎么用里面的 {{变量}}

每条话术里有 {{姓名}} {{司龄}} {{年假总额}} 这种占位符。复制到聊天框后，手工替换成实际数字再发。

建议：每回答一个新问题就顺手在系统里"新建回复"一条存着。下次再有员工问，你两秒钟就能发出去。

13场景十：要写通知/证明/offer

回答：进"文书生成"。

系统预置了 10 个常用模板：

分类模板
JDJD-技术开发岗 / JD-销售岗
通知转正通知 / 调薪通知 / 试用期延长通知 / 会议通知 / 入职欢迎信
offer录用通知书

使用步骤

3.填其余变量（比如薪资、报到日期）→ 点 生成预览。

                                         {{开具日期}}

保存后下次直接调用。已有模板也可以点"编辑模板"改。

14场景十一：入离职手续怎么不漏项

回答：进"入离职清单"。

系统内置了两套清单，新人入职时直接用：

  • 入职 13 项：身份证复印件、学历核验、离职证明、体检报告、银行卡登记、劳动合同、工号开通、企业微信/邮箱开通、工牌、门禁、办公用品、入职培训、欢迎信
  • 离职 10 项：离职申请、交接、账号关闭、工牌归还、用品归还、借款结清、社保停缴、离职证明、工资结算、关怀访谈

使用

1.填员工姓名、选"入职"或"离职" → 点 生成清单。
2.每办完一项，点前面的复选框勾选——系统自动记进度，进度条也会跟着走。

如果某次情况特殊，要加/减项，在"自定义清单项"里用逗号分隔写清楚就行。

所有人的清单会一直留在"进行中的清单"区，随时打开接着勾。

15场景十二：被问"制度上怎么写的"

回答：进"制度知识库"。

把你们公司现行的《考勤管理制度》《薪酬管理办法》《员工手册》等上传到知识库——系统会按"第X条"自动切片，每一条独立保存、可单独搜到。

怎么上传

"上传制度文档"区，选文件（支持 txt / md / docx / 文字版 pdf），填标题、分类（制度/流程/模板/法规）、版本、生效日期 → 点 上传并切片入库。

怎么查

顶部"制度检索"输入框输关键词，比如员工问"病假工资怎么算"，你搜"病假"——结果会列出命中的条款原文，并标注来源（哪份文档、第几条、版本号）。

把命中的条款念给员工听、或者直接截图发过去——比你自己凭记忆复述要严谨得多，也不会出错。

扫描件 PDF 不支持——一期不做图片识别。如果是图片型 PDF，请先用 Word 或 OCR 工具转成文字版再上传。

17安全与隐私

员工档案里有身份证号、银行卡号——这是最敏感的数据。系统做了三层保护：

  1. 默认只能本机访问（127.0.0.1），外人通过网络打不开。
  2. 身份证 / 银行卡在页面默认显示为掩码（如 110***********1234），防止旁边有人偷看。
  3. 如果你的电脑要开放给同事用（局域网共享），必须在 配置.yaml 里设置访问口令，否则程序会直接拒绝启动——这是为了防止数据被外人访问。
建议：
① 离开工位时随手 Win + L 锁屏；
② 不要把 data/ 目录拷给不相干的人；
③ 公司电脑建议每晚关机（自动备份会跟随下次启动执行）。

18常见问题

双击 bat 后浏览器没自动打开？

看下黑色窗口里显示的地址（一般是 http://127.0.0.1:5270），手动复制到浏览器打开就行。

提示"端口被占用"？

系统会自动换 5271、5272……看黑色窗口显示的实际地址。如果都被占了，关掉别的程序再试。

上传 PDF 后系统说"未提取到文本"？

这个 PDF 是扫描件（由图片组成的）。请先用 Word 或 OCR 工具转成文字版再上传。

Excel 导入失败？

检查：①表头与模板一致；②日期用 2026-08-31 这种格式；③手机号/工号列设成"文本"，不要被 Excel 自动改成科学计数法。

点"完成"按钮后悔了？

待办目前只支持"完成"，没有撤销按钮。重要的事想清楚再点，或者新建一条手动的把信息记下来。

数据会传到公司服务器吗？

不会。这是一个完全离线的程序，所有数据只存在你电脑的 data/ 目录里，不连外网、不连公司内网。你可以打开任务管理器看：程序连不上任何 IP。

多人能同时用吗？

本机单用户版。如果部门多人要协同，需要把 host 改为 0.0.0.0 并设访问口令——但要清楚，数据库还是单机 SQLite，多人同时写可能冲突。多用户版本是二期计划，本期建议还是自己电脑自己用。

出了 bug 怎么办？

截图发给你的管理员（或者提出这个问题的人），附上操作步骤和数据情况。如果能保留 data/ 目录不要删，方便定位问题。
